# 🚗 Análise de Acidentes de Trânsito nas Rodovias Federais (PRF 2026)

Projeto de Análise Exploratória de Dados (EDA) utilizando Python, Pandas e Google Looker Studio para explorar informações sobre acidentes de trânsito registrados nas rodovias federais brasileiras.

## 📌 Objetivo

O objetivo deste projeto é realizar o tratamento, limpeza e análise dos dados de acidentes de trânsito, gerando visualizações que auxiliem na identificação de padrões e fatores associados aos acidentes.

## 📊 Etapas do Projeto

### 1. Coleta dos Dados

Utilização de um conjunto de dados contendo registros de acidentes nas rodovias federais brasileiras.

### 2. Tratamento dos Dados

Foram realizadas etapas como:

- Remoção de valores inválidos
- Padronização de colunas
- Ajuste da codificação para UTF-8
- Conversão de tipos de dados
- Preparação do conjunto para visualização

### 3. Análise Exploratória

Análise das principais variáveis do conjunto de dados, incluindo:

- Quantidade de acidentes por estado
- Principais causas dos acidentes
- Tipos de acidente
- Condições meteorológicas
- Fase do dia
- Dias da semana com maior ocorrência
- Distribuição por rodovias (BR)
- Evolução temporal dos acidentes

### 4. Dashboard

Foi desenvolvido um dashboard interativo no Google Looker Studio contendo filtros e gráficos para facilitar a exploração dos dados.

# 📈 Visualizações

O dashboard apresenta gráficos como:

- 📍 Acidentes por Estado
